## 현재 동작

- 하단 피드 탭으로 홈과 피드 사이를 이동합니다.
- 첫 진입 시 좌우 이미지 탐색과 위로 넘기기 안내를 표시하고 화면을 누르면 닫힙니다.
- 위아래 스와이프로 경매 상품을 전환합니다.
- 좌우 스와이프로 한 상품의 이미지 페이지를 전환하며 페이지 번호와 점 표시가 함께 바뀝니다.
- 찜 선택 시 오른쪽 하트가 채워지고 중앙에 큰 하트 피드백이 잠시 나타납니다. 선택 해제도 동작합니다.
- 남은 시간 카운트다운과 새로고침 안내가 동작합니다.
- 상품명과 상세보기를 누르면 해당 상품 상세 화면으로 이동합니다.
- 입찰 버튼을 누르면 피드 위에 입찰 바텀시트가 열립니다. 현재가보다 큰 금액과 등록 결제수단·배송지를 확인하고 입찰이 완료되면 피드 가격과 입찰 수가 갱신됩니다.
- 남은 시간이 1분 미만이면 타이머를 코랄색으로 강조합니다. 30초 이내 새 입찰이면 남은 시간에 15초를 더하고 연장 안내를 표시합니다.
- 남은 시간이 0초가 되면 경매 종료 상태와 비활성 입찰 버튼을 표시합니다.

피드 데이터와 이미지 영역은 현재 로컬 예시 상태입니다. 영상 재생, 서버 새로고침, 서버 찜 저장은 API와 미디어 에셋 연결 단계에서 교체합니다.
