# dib Android 디자인 기준

화면은 흰색과 밝은 회색을 바탕으로 정보를 간결하게 배치하고, 행동의 의미에 따라 네이비·민트·코랄을 제한적으로 사용합니다.

| 역할 | 색상 | 용도 |
| --- | --- | --- |
| Primary Navy | `#13284B` | 주요 버튼, 선택 상태, 핵심 텍스트 |
| Mint | `#BDEEDF` | 성공 피드백, 브랜드 강조 |
| Mint Ink | `#216551` | 민트 배경 위 텍스트 |
| Live Coral | `#EF596B` | LIVE 상태, 긴박한 입찰 |
| Favorite Pink | `#FF5277` | 선택된 찜 아이콘 |
| Text | `#17212D` | 기본 본문 |
| Muted | `#626B76` | 보조 정보 |
| Border | `#E7EAEE` | 카드와 입력창 경계 |
| Surface | `#F5F6F7` | 화면·이미지 자리 배경 |

기본 화면 여백은 16dp, 카드 모서리는 12~14dp, 최소 터치 영역은 44dp를 사용합니다. 찜은 모든 화면에서 같은 outline/filled 벡터를 사용하고, 목록 성격의 화면은 공통 카드·목록 전환 컴포넌트를 사용합니다.
